# Setup Guide

## Prerequisites
- Node.js (Latest LTS recommended)
- Supabase Project
- Gemini API Key

## Installation
1. Install dependencies: `npm install`
2. Set up environment: Copy `.env.local.example` to `.env.local` and populate keys.
3. Run: `npm run dev`
