- Browser verification showed only the black mounted placeholder before restart; failed resources included `/_next/static/chunks/main-app.js`, `/_next/static/chunks/app/page.js`, and `/_next/static/css/app/layout.css`.
- Restarted the dev server with `npm run dev` and verified via Playwright that `#portal-title`, `#signin-heading`, Google login, email input, and Magic Link content render with no failed browser resources or console errors.
