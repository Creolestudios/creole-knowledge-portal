# Changelog: 2026-05-27

This entry represents the baseline system configuration and initial release of the Creole Knowledge Portal documentation.

---

## ➕ Added

- Standard Next.js 15 App Router configuration with React 19 and Tailwind CSS 4 setup.
- Secure session cookie configuration via `@supabase/ssr` server client wrappers.
- Passwordless login screen (`/`) supporting both Google OAuth authentication and magic links.
- Edge authentication router middleware (`middleware.ts`) to secure `/dashboard` and `/admin/dashboard` routes.
- Hardcoded security gate for administrative access restricted to `priya.dhanani@creolestudios.com`.
- Administrative interface (`/admin/dashboard`) containing:
  - UserManagement dashboard list to review profiles and configure employee tags.
  - Blog Sources panel to configure and validate target tech feeds.
- Server-side admin route `/api/admin/users` to fetch database user lists and merge authentication details with metadata.
- Prettier, ESLint configuration templates, and testing infrastructure using Vitest.
- Local CI gate automation scripts (`scripts/ci-test.sh`) to run tests and output JSON reports in `/reports`.

---

## 🔄 Changed

- Transitioned routing guards from client-side verification to Next.js Edge Middleware for improved security and performance.
- Refined OAuth and email Magic Link callbacks to support custom origins dynamically.

---

## 🛠️ Fixed

- Resolved redirection loops in standard user profiles by propagating cookies correctly inside the Edge Middleware.
- Fixed layout shift issues on login forms by implementing a Client Component mounting flag.

---

## ❌ Removed

- Retired client-side environment secrets to prevent accidental token exposure.
