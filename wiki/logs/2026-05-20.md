# 2026-05-20

## Localhost Dev Server Recovery

- Investigated `localhost:3000` not loading after browser launch.
- Root cause: overlapping `next dev`/`npm run dev` processes left a corrupted `.next` dev cache, producing missing webpack chunks such as `./611.js` and missing `.next/routes-manifest.json`.
- Stopped duplicate dev servers, removed the generated `.next` cache, and restarted a single clean `npm run dev` process.
- Validation: `curl -I http://localhost:3000` returns `200 OK`; `curl -I http://localhost:3000/dashboard` returns `307 Temporary Redirect` to `/` when unauthenticated, matching middleware behavior.

## Devtools Manifest Error Recovery

- Re-investigated `localhost:3000` after the dashboard intermittently failed during authenticated reloads.
- Root cause: Next.js dev runtime/React Server Components manifest corruption involving `next-devtools/userspace/app/segment-explorer-node.js#SegmentViewNode`, followed by `__webpack_modules__[moduleId] is not a function` on `/dashboard`.
- Restarted from a clean `.next` cache with `DISABLE_HMR=true npm run dev`, using the existing `next.config.ts` watchOptions guard to avoid hot-reload cache churn.
- Validation: `curl -I http://localhost:3000` returns `200 OK`; unauthenticated `/dashboard` returns `307 Temporary Redirect` to `/`.
