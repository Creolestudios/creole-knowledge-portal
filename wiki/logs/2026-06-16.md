# Project Log — 2026-06-16

## Added
- **AI Detection Module** (`lib/blog-roulette/ai-detection.ts`): Gemini-powered + heuristic fallback for estimating AI-generated content likelihood. Returns score 0–100 with human-readable signals. Free tier on Gemini 2.5 Flash.
- **AI Score API** (`GET /api/blog-roulette/:id/ai-score`): Endpoint that runs detection on blog body, persists score, returns result for the editor sidebar.
- **Live Preview Pane** (`components/blog-roulette/preview-pane.tsx`): Rendered HTML preview with Mermaid diagram support, SEO preview card, AI score banner, live word count and reading time.
- **Mermaid Diagram Support**: Mermaid.js integration in preview pane — renders `<pre class="mermaid">` diagrams from blog content. Code-split via dynamic import.
- **Image Upload API** (`POST /api/blog-roulette/upload`): Supabase Storage upload for blog cover + inline images. Creates `blog-images` bucket on first use. Accepts jpeg/png/webp/gif/svg, max 5 MB.
- **Storage Bucket Migration** (`20260616120000_blog_roulette_storage.sql`): RLS policies for public read, authenticated upload, author-scoped delete.

## Changed
- **Blog Editor** (`app/blog-roulette/[id]/edit/page.tsx`):
  - Replaced hardcoded `ai_score: 30` with live AI detection score from the new module.
  - Added debounced AI detection (3s after typing stops) with real-time sidebar score display.
  - Added Preview toggle button in toolbar — swaps TinyMCE editor with rendered PreviewPane.
  - Added inline image upload button next to cover image URL field.
  - AI score shown in Live Stats sidebar with color-coded status (green/amber/red).

## Technical Notes
- AI detection uses Gemini 2.5 Flash by default (free tier, 1M TPD). Falls back to heuristic perplexity-style analysis (lexical diversity, sentence variance, filler-word density, pronoun scarcity) when API unavailable.
- Mermaid is code-split (`import('mermaid')`) — only loaded when preview pane mounts.
- Image upload creates the Supabase storage bucket lazily on first upload if missing.
