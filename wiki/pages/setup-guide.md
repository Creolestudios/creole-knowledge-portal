# Setup & Installation Guide

This document describes the steps required to clone, configure, install, test, and run the **Creole Knowledge Portal** codebase on your local machine.

---

## 🛠️ Prerequisites

Before starting, ensure you have the following software installed:

- **Node.js**: Version 18.x or 20.x (Recommended)
- **NPM**: Version 9.x or newer
- **Supabase Account**: Access to a project instance for database tables and authentication configs.
- **Google Cloud Console Project**: For configuring Google OAuth logins.

---

## ⚙️ Environment Variables

The application reads secrets and API configuration targets from environment files.
Create a `.env.local` file in the root directory. Use `.env.example` as a starting point.

Copy the example template:

```bash
cp .env.example .env.local
```

Configure the following environment variables:

| Variable Name                   | Required     | Description                                                                                    |
| ------------------------------- | ------------ | ---------------------------------------------------------------------------------------------- |
| `NEXT_PUBLIC_SUPABASE_URL`      | Yes          | The API URL endpoint of your Supabase project (e.g. `https://xxx.supabase.co`).                |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Yes          | The client-safe API key for database access and auth callbacks.                                |
| `SUPABASE_SERVICE_ROLE_KEY`     | Yes (Server) | High-privilege API bypass key for administrative calls. **Do NOT prefix with `NEXT_PUBLIC_`**. |
| `GEMINI_API_KEY`                | Yes (Server) | Google Gemini AI developer API token for text summarization.                                   |
| `GOOGLE_CLIENT_ID`              | Yes          | Google Client ID for OAuth flow.                                                               |
| `GOOGLE_CLIENT_SECRET`          | Yes          | Google Client Secret for OAuth flow.                                                           |

## 📦 Local Installation

Follow these steps to run the portal:

### 1. Install Project Dependencies

Run the installation command in the workspace root directory:

```bash
npm install
```

### 2. Configure Database Schema

Execute the following SQL queries inside your Supabase SQL Editor to initialize the database tables:

```sql
-- Create user profiles table
create table public.user_profiles (
  user_id uuid references auth.users(id) on delete cascade primary key,
  email text not null,
  current_role text,
  years_of_experience integer,
  primary_tech_stack text[] default '{}'::text[],
  secondary_tech_stack text[] default '{}'::text[],
  future_interests text,
  updated_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Enable RLS for profiles
alter table public.user_profiles enable row level security;

-- Create blog sources table
create table public.blog_sources (
  id bigint generated by default as identity primary key,
  url text not null,
  added_by uuid references auth.users(id) on delete cascade,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Enable RLS for blog sources
alter table public.blog_sources enable row level security;
```

## 🚀 CLI Commands Reference

Execute these NPM scripts for local development and quality control:

| Command                   | Action                                                                                           |
| ------------------------- | ------------------------------------------------------------------------------------------------ |
| `npm run dev`             | Spins up the Next.js local development server on [http://localhost:3000](http://localhost:3000). |
| `npm run build`           | Compiles the Next.js frontend application into an optimized standalone production bundle.        |
| `npm run start`           | Boots the compiled standalone production server.                                                 |
| `npm run lint`            | Analyzes code quality using ESLint.                                                              |
| `npm run lint:report`     | Runs ESLint and exports output directly to `reports/eslint-report.json`.                         |
| `npm run format:check`    | Verifies style compliance across source code using Prettier.                                     |
| `npm run test`            | Executes unit tests once via Vitest.                                                             |
| `npm run test:report`     | Executes unit tests and outputs report to `reports/test-report.json`.                            |
| `bash scripts/ci-test.sh` | Local quality gate simulation: runs linter, tests, and formatting checks, creating reports.      |
