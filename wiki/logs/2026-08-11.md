# Changelog: 2026-08-11

Infrastructure scaffold for **Option 3** (TGN pattern) on branch `feat/infra`.

---

## Decision

- **Option 3 — dedicated data stores in shared VPC** (aligned with [`stogo-factory`](../../TGN/projects/stogo-factory) / TGN `option3-isolated-db`).
- **Supabase stays external** — Auth and quiz PostgreSQL are not provisioned by Pulumi.
- **CKP-specific services**: Next.js web (:3000), FastAPI api (:8000), Celery workers (no HTTP port).
- **Data**: MongoDB + Redis dedicated in VPC (ElastiCache / DocumentDB placeholders); connection strings via Pulumi config until full modules land.

---

## Branch purpose

`feat/infra` holds infrastructure-as-code and deployment manifest work, merged from feature branches (srushti, orch, priya, quiz) at `d727ea3`. Application code and infra evolve together here before a production deploy path is finalized.

---

## Deploy prerequisites

1. Existing shared platform: VPC, private subnets, ECS cluster, shared ALB listener.
2. AWS credentials (`AWS_PROFILE`) and Pulumi CLI.
3. Pulumi config for `sharedVpcId`, `sharedPrivateSubnetIds`, `sharedAlbListenerArn`, `sharedEcsClusterArn`, etc. (see `infra/README.md`).
4. ECR push access for web, api, and workers images.
5. External Supabase project URL + keys; Gemini API key — injected at deploy, not in repo.
6. Mongo/Redis URLs until ElastiCache/DocumentDB modules are implemented.
